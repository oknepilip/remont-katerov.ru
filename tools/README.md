# Сборка сайта

- `tools/content.py` — все тексты: услуги, кейсы, FAQ, страница для коммерческих судов.
- `tools/src/site.css`, `tools/src/site.js` — общий стиль, формы и сценарии Стармеха.
- `python3 tools/build.py` — собирает предпросмотр в `/preview/` (закрыт от поисковиков, видны заметки для владельца).
- `python3 tools/build.py --live` — собирает сайт в корень: индексируется, пишет `sitemap.xml`, подключает Метрику.

Цены: в `content.py` у работы можно указать цену, например `("ТО двигателя", "от 15 000 ₽")`.
Адрес страницы с `?test=1` не отправляет заявки, текст заявки пишется в консоль браузера.
